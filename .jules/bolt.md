## 2025-05-22 - [Generator] Caching Prompt builder with custom __setattr__
**Learning:** In `adalflow`, `Generator` (via `Component`) has a complex `__setattr__` that manages parameter and component registration. When adding internal caches (like `_prompt_builder`), using `object.__setattr__` is essential to avoid these caches being mistakenly registered as public components or causing `AttributeError` during early initialization. Additionally, overriding `__setattr__` in the subclass is an effective way to implement cache invalidation for specific attributes (e.g., `template`, `prompt_kwargs`).
**Action:** Use `object.__setattr__` for private internal state in `Component` subclasses to avoid registry side effects, and explicitly override `__setattr__` for reactive cache invalidation.
