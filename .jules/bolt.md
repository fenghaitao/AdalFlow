## 2026-03-31 - Hoisting container inspections in dataclass serialization/deserialization helpers
**Learning:** In recursive dataclass helpers like `dataclass_obj_from_dict` and `_asdict_inner`, inspecting field args or checking exclude lists repeatedly inside element loops introduces significant per-element function call and type evaluation overhead (~3.4x speedup when hoisted). Additionally, unconditional f-string formatting in `log.debug(...)` calls constructs expensive string representations even when debug logging is inactive.
**Action:** Always inspect generic type parameters (`cls.__args__`) and pre-compute exclude sets once outside element iteration loops, fast-path primitive non-dataclass containers, and use lazy log formatting (`log.isEnabledFor(logging.DEBUG)` or `%s` specifiers) in hot recursive routines.
